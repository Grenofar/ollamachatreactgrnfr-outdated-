Ollama Chat React

Bonjour. Avec cette app, discutez avec des LLM en local.

Une application de bureau qui vous connecte à Ollama pour discuter avec des modèles de langage sur votre PC, et qui inclut Codex, un éditeur où un modèle agit en agent sur vos fichiers. Tout tourne en local, rien n'est envoyé sur le web.

Comment ça marche

Chat

Choisissez un modèle installé dans Ollama, discutez normalement — l'app garde vos conversations en local.

Codex

Ouvrez un dossier, décrivez ce que vous voulez : le modèle lit, écrit et modifie des fichiers, exécute des commandes, et vous demande votre avis avant chaque action si vous êtes en mode Approbation.

Note Windows : l'installeur n'est pas encore signé numériquement, donc Windows peut afficher un avertissement SmartScreen ("Éditeur inconnu") au premier lancement. Cliquez sur "Informations complémentaires" puis "Exécuter quand même" pour continuer.
