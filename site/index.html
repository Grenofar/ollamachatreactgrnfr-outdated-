Chattez avec Ollama.
Codez avec un agent local.

Un client de chat pour Ollama qui tourne entièrement sur votre PC, avec en plus un éditeur de code façon VS Code où un modèle local agit en agent : il lit, écrit et modifie des fichiers, exécute des commandes, et vous demande votre avis quand il le faut. Rien de tout ça ne s'exécute dans un navigateur — c'est une vraie application installée.

Vérification…
Windows 10/11 · installation locale, aucune donnée envoyée sur le web

Ce que ça fait

Deux outils dans une seule application, tous les deux 100% locaux.

Chat Ollama

Conversations, réglages, installation de modèles et recherche de modèles GGUF sur Hugging Face — tout passe par votre serveur Ollama local, rien n'est envoyé ailleurs.

Éditeur Codex agentique

Un modèle Ollama lit et modifie des fichiers sur votre PC, liste des dossiers, exécute des commandes PowerShell et vous pose une question quand une décision vous revient.

Auto / Approbation

Comme le mode d'édition de Claude Code : chaque action qui modifie quelque chose peut être validée via un diff avant d'être appliquée, ou passer en automatique si vous préférez.
