Publier une extension

Comment ça marche : le contenu est ajouté au prompt système du modèle (chat de base ou Control Me, selon la cible choisie) — pas de code exécuté, pas d'accès direct au système. Avant publication, Gemini 3.7 analyse le contenu ; s'il le juge à risque (instructions cachées, tentative de manipulation de l'IA...), la publication est refusée. Une fois publiée, une extension reste marquée non officielle (orange) sauf revue manuelle explicite — les utilisateurs sont prévenus avant d'installer. Détail complet et exemples : documentation.
